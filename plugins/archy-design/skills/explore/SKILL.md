# Explore on brand

For designers. Load the brand skill for the identity in question first (`archy:brand`, `archy:offsite-brand`, or the DOC brand skill). Everything in it applies: non-negotiables, tokens, type, Rulers, la mascota, logo lockups, voice, scale and restraint.

**The Archy system replaces the generic design brief.** Paper's own guide asks for a mood word, a palette and a type scale before designing; for these brands they already exist. Skip the mood/palette brief, and instead state in one or two lines the direction you are taking within the system (ground, composition, what leads).

## How to work

1. **Understand the ask**: format and size, where it will be seen, the one message it must carry, the facts. For the formats the team already uses, start from their sizes and safe areas (`composition.md`, *Event three-format family*).
2. **Work in the designer's file or a new one**, never in a `Master - …` file. Borrow freely from the templates: duplicate artboards or clone pieces (lockups, badges, pills, la mascota) with `<x-paper-clone>` rather than redrawing them.
3. **Offer real alternatives** when asked for directions: two or three that differ in ground, composition and what leads, not three colourways of one layout.
4. **Build in small steps and screenshot often.** Run `review-checklist.md` before showing anything, and apply *Scale and restraint*: type bigger than feels safe, gaps tighter, radii from the tokens, no decoration without a job.
5. **Report** what you made, the choices that bend a default and why.

## When an exploration should become a template

If the piece is a layout the marketing team will reuse, and it holds a content shape no template has, finish it with the `prepare-template` skill so it lands in the right `Master - …` file with named slots and a catalog entry.

## When you learn something

If the work produced a rule worth keeping (a new pattern, a correction, a Paper quirk), offer to add it with the `publish` skill.
